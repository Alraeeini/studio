# Studio

Repository personale per organizzare materiali e studiare una materia alla volta.

La cartella **studio/** è la dashboard principale. Ogni materia ha una cartella separata con i file originali e la memoria di continuità per ChatGPT.

- [Computer Logic](studio/Computer%20Logic/README.md) — materiali presenti; classificazione di alcuni file da confermare.
- [Calculus 1](studio/Calculus%201/README.md) — cartella pronta, in attesa dei materiali del corso.
- [Skill universale di studio](studio/STUDY_SKILL.md) — metodo riutilizzabile per qualsiasi materia.

## Regole rapide
1. Carica i file originali nella cartella della materia corretta.
2. In una nuova chat chiedi a ChatGPT di leggere studio/README.md e i file di continuità.
3. Studia un argomento per volta.
4. Alla fine aggiorna progressi, contesto, appunti e registro, se l'integrazione consente di scrivere nel repository.
5. Se non può salvare su GitHub, deve dichiararlo e fornirti i contenuti aggiornati da copiare.

I file memorizzano informazioni didattiche e stato operativo, non ragionamenti interni nascosti.
