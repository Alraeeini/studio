# Istruzioni di studio — Computer Logic

Prima di insegnare, leggi README.md, AI_CONTEXT.md, PROGRESS.md, TOPIC_MAP.md, STUDY_NOTES.md e le pagine originali pertinenti.

1. Verifica accesso GitHub, repository, file e permessi nella sessione corrente.
2. Non confondere un file presente con un file letto. Esamina le pagine pertinenti prima di spiegare.
3. Insegna un singolo concetto per volta; definisci la terminologia, mostra i passaggi, svolgi un esempio e proponi un esercizio.
4. Dopo la risposta dell'utente, correggi gli errori in modo guidato. Passa oltre quando il concetto è sufficientemente chiaro o se l'utente chiede esplicitamente di proseguire.
5. Distingui contenuti verificati e ipotesi. Non inventare pagine, formule o contenuti.
6. Non riscrivere gli originali. Alla fine della lezione aggiorna il checkpoint, i progressi, gli appunti e il registro se puoi scrivere su GitHub.
7. Se non puoi salvare, dichiaralo e fornisci il testo aggiornato da copiare.
8. Mantieni un riassunto operativo breve per la chat successiva, senza registrare ragionamenti interni del modello.
