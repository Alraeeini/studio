# Template materia

Copia questa struttura per ogni nuova materia.

1. Crea una cartella con il nome della materia.
2. Copia al suo interno i file del template.
3. Aggiorna nome e prerequisiti in README.md e AI_CONTEXT.md.
4. Carica gli originali nella cartella della materia.
5. Chiedi a ChatGPT di verificare i file, creare la mappa e insegnare il primo argomento.

File previsti: README.md, AI_INSTRUCTIONS.md, AI_CONTEXT.md, TOPIC_MAP.md, PROGRESS.md, STUDY_NOTES.md, SESSION_LOG.md.
